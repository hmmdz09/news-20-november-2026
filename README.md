An original front page summing up the world's news of Friday 20 November 2026: 35 stories from six continents: three illustrated leads, ten drawn cards, a locator map, 22 briefs and a date check. `src/page.html` (HTML with inline SVG drawings) is rendered to the 1024×1024 `entry.png`, and `main.ts` copies it to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
